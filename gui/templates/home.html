This GUI demonstrates the banking database project. It shows how ownership, account access, transactions, draft transfers, booking, and interest calculation work together.

  • See whether access is owner access or granted access
  • See whether the person can only view or can also transfer
  • Create draft transfers from accounts with transfer permission
  • Book draft transfers using a stored procedure
  • Show account statements with balance and transactions
  • Calculate monthly interest using a stored procedure
